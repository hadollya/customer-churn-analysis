تحليل انسحاب العملاء (Customer Churn Analysis)

نبذة عن المشروع
يهدف هذا المشروع إلى تحليل انسحاب العملاء من الاشتراكات، وتحديد العوامل المرتبطة بإلغاء الاشتراك، وتقييم أداء نموذج إحصائي للتنبؤ بالعملاء المحتمل انسحابهم.

أهداف المشروع
- تحليل أنماط انسحاب العملاء.
- تحديد العوامل المرتبطة بإلغاء الاشتراك.
- بناء نموذج انحدار لوجستي وتقييم أدائه.
- تقديم توصيات عملية للمساعدة في تقليل الانسحاب.

الأدوات المستخدمة
- Python لتحليل البيانات وبناء النموذج التنبؤي.
- Pandas وNumPy لمعالجة البيانات.
- Statsmodels للتحليل الإحصائي.
- Scikit-learn لتقييم النموذج.
- Power BI لاستكشاف البيانات وتحليلها.

ملفات المشروع
- `churn_analysis.py`: كود تحليل البيانات وبناء النموذج وتقييم أدائه.
- `تقرير تحليل انسحاب العملاء.pdf`: التقرير النهائي الذي يتضمن المنهجية والنتائج والتوصيات.

أبرز النتائج
- بلغت نسبة انسحاب العملاء 9.29%.
- ارتبط ارتفاع عدد تذاكر الدعم بزيادة احتمالات الانسحاب.
- ارتبط إكمال التهيئة الأولية للعملاء بانخفاض احتمالات الانسحاب.
- حقق النموذج التنبؤي قيمة ROC-AUC بلغت نحو 0.63.

التوصية
تجربة تحسين إجراءات التهيئة الأولية للعملاء، ثم قياس أثر هذه التحسينات على معدلات الاحتفاظ بالعملاء.

ملاحظة
توضح النتائج علاقات إحصائية بين المتغيرات، لكنها لا تثبت أن أحد العوامل تسبب مباشرةً في انسحاب العملاء.
